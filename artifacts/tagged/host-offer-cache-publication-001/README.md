# 宿主准入查询缓存：等价性验证发布

本批是[宿主 C++ 实现优化](../../../docs/mlx-host-admission-cache.md)，不是模型推理性能结果，也不修改 ISA、调度策略、模拟周期或硬件容量。

- [182 项回归](../host-offer-cache-tests-001/regression.xml)通过。
- [10 个完整登记图](../host-offer-cache-equivalence-001/report.json)与原二进制的输出、事件、周期和资源记录完全相同，并通过 ASan/UBSan/泄漏检查；另有资源边沿/缓存失效契约检查。
- [原始插桩](../host-hotspots-baseline-001/report.json)用于定位约150万次准入查询的开销，保留原 gprof 记录，不把插桩耗时当真实模型速度。
- 四次交替宿主测量的组件中位数为旧版约3.72秒、新版约3.17秒；组件有效MAC数262144、含读回周期1556698保持不变。该组件宿主开销差异不能外推到完整模型、GPU或RTL。

[manifest.json](manifest.json) 绑定 141 个文件、8732800 字节（不含本索引及 manifest 自身）。只缓存当前资源版本、当前 PE 的失败查询；分配、边沿末回收及驻留限制变更使旧结果失效，调用者和范围检查仍执行。

基线来自父提交 `2e58eb0` 的源码。历史 gprof 来源摘要描述优化前版本，不声称与当前资源实现一致。宿主大二进制、构建目录、环境链接、模型权重及四个运行中的完整模型产物未纳入发布；输入/结果路径按历史记录保留，复现应使用新目录。

分支 `mlx-host-opt-v1` 独立于三个冻结工作树，没有替换四个长任务的实现。完整模型正确性、全部模型/输入、原 GPU 门槛、系统推理性能、一般 CDC 与 RTL 的门槛仍未关闭。
