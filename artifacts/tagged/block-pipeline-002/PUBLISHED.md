# 有界块事件组件发布范围

发布内容为正式报告、212项回归XML、六个代表性程序/配置/结果及输出：同资源流水/完整生产者屏障对照、16-PE FP32尾块、mean行生产者、矩阵batch和三步生成。其余完整测试及20个ASan/UBSan/LSan重放工作集保留本地，摘要由报告绑定，可通过验证脚本在新目录复现。

这些证据验证闭合双算子组的部分结果事件、资源预约与实际数值执行，不代表一般CDC、完整论文ISA、全部模型或系统性能通过。新增事件存储为单独声明的有界控制状态，不能算作免费RF/SPM容量。

完整Llama2只生成了873个编译分组，并进行了1周期限额启动检查；节点/资产/数值程序没有缩减，也没有完整推理结果。`startup.log`中的退出1是预设周期上限，不能改标为完整模型通过。模型权重和构建二进制没有发布。
