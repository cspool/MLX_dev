# 共享阵列组件发布范围

本目录发布正式报告、158项回归XML及5个代表性实际C++用例的完整job、result和数值输出：两种混合帧顺序/精度、全局周期/II、ROM容量等待和4-PE物理重试。它们是组件验证，不是完整模型、完整CDC、系统或推理性能通过。

14组旧/新可执行文件对照和14个ASan/UBSan/LSan作业已实际结束并核对；对应摘要/范围在`report.json`，完整原始测试工作集保留在本地，并未全部推送。二进制、临时构建和模型权重不随本目录发布。按`scripts.verify_mlx_shared_array`指定新输出目录可以重放，旧二进制需提供报告中相同摘要的文件，不能随意替换为当前重建文件后声称同一对照。

代码位于独立分支`mlx-shared-array-v1`。在主工作树两项完整运行结束并完成各自核验前不合并到`sys`，不重新标注它们已经使用本分支。
