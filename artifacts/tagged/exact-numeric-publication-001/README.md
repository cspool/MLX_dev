# 精确 FP16 投影诊断：证据发布

本批发布[整数精确参考与 Q/K/V 诊断](../../../docs/mlx-exact-projection-diagnosis.md)，不修改 MLX 数值规则、原 GPU 参考、验收阈值或运行中的模型。

- [14 项测试及安全重放](../exact-numeric-validation-001/report.json)：257952 个精确舍入检查点，独立大整数点积及非法输入拒绝。
- [完整投影诊断](../exact-projection-diagnosis-002/report.json)：同一实际输入和完整真实权重，共98304个输出、402653184个精确整数乘积。微程序输出与独立逐K FP32乘加逐字节一致，ASan/UBSan/泄漏检查结果一致。
- [GPU 选库与 split-K 对照](../gpu-splitk-diagnosis-002/report.json)：九次输出均复现历史 GPU 观察；这些设置变化没有消除当前差异。首次不支持的配置保留失败记录，不标为模型失败。

[manifest.json](manifest.json) 绑定本批 98 个文件、8958047 字节（不含本索引和 manifest 自身）。包括诊断代码、测试输入/输出、精确结果、GPU对照及来源摘要；不包含模型权重、构建目录或四个活动完整模型的输出。历史绝对路径保留用于溯源，复现请使用新输出目录。

这里使用保存的中间值只用于孤立算子比较，不把精确/参考结果送回模型。首层投影的数值路径解释不能代表所有层、完整模型或系统正确性通过，也不能证明 GPU 内部具体算法。原 GPU 完整 logits 门槛、全部所需模型/输入、性能和 RTL 仍未通过。
