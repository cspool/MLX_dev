- C++ tagged-block 准入、上下文发射、资源/事件/访存模型，及相应编译器、runtime 和回归测试。
- 矩阵、向量、搬运、控制后端与共享物理存储；真实 RV64/Rocket 的编译任务表、RoCC/cache 桥、16GiB 受检地址空间及驻留资产镜像。

`files.txt` 是经过筛选的提交文件清单；`SHA256SUMS` 记录这些代码、说明和结果文件的摘要，不包含它自身。发布前37个测试文件的865项回归全部通过，0失败、0跳过，宿主耗时159.10秒，结果保存在同目录的 `regression.xml`；这不是目标推理性能。组件源码身份与历史报告的对应关系另见 `evidence-source-audit.json`；摘要不同的历史证据不能单独作为当前版本证书。

真实Rocket进度观察的已结束预检另行复核为 `system-preflight.json`：正常/观测两次45节点执行输出与完整设备事件/周期一致。这份报告明确不是随后的完整模型通过结果。

已完成的 Llama2 数值契约检查与原 GPU 误差门槛分别记录：前者的一致性不覆盖后者的失败。原 GPU 比较报告随历史数值证据一起保留。完整模型、全部目标模型/输入、跨算子共享资源及系统性能验收仍未完成；不开放推理性能或完整 RTL 验收。

模型权重、完整 checkpoint、构建目录、独占模拟器二进制、运行中的日志/进程状态JSON、临时测试工作目录和大型中间激活不推送。报告中的本地绝对路径仅是原始证据的来源记录；未随 Git 发布的原始工作集需要按对应脚本重新生成，不能仅凭摘要重建其内容。
