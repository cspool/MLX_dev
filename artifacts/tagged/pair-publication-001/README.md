# 双算子系统接口：阶段性验收产物

本目录索引 `mlx-shared-array-v1` 分支的有限双算子调度及真实 Rocket 系统接口增量。它不是完整 MLX 模型/系统、GPU 数值一致性、推理性能或 RTL 的完成声明。

- [接口与范围说明](../../../docs/mlx-pair-system-abi.md)
- [组件验证](../pair-wire-001/report.json)：204 项回归、19 个 ASan/UBSan/LSan 用例。
- [真实 Rocket 验证](../pair-rocket-001/report.json)：7 个 ELF 正常退出，13 次双算子启动，包含实际 token 回馈与扰动检查。
- [既有图兼容性记录](../pair-system-build-002/report.json)：此前 45 节点图在新系统构建上通过。

[manifest.json](manifest.json) 记录本批 122 个代码/文档/证据文件的 SHA-256、大小及发布前交叉核对结果，不包含本索引和 manifest 自身。发布前核对了三份报告的全部来源摘要（149、147、145 项），并确认本批新源码连同已有 Git 文件覆盖报告来源。

发布完整的 19 个组件 job/report、全部 7 个 Rocket 用例的 C 源码、小型 ELF、双算子/控制描述符、期望 token、执行记录及设备结果。19 份 sanitizer JSON 与对应已发布 release report **逐字节相同**，因此不重复存放；其原始摘要仍在组件报告中。报告中的预期错误用例保持失败设备状态，不会改写为正常完成。

未包含模型权重、环境链接、Chipyard 构建树、宿主模拟器二进制及仍在运行的完整模型输出。大二进制和运行库保留摘要，复现需要按项目流程本地构建。兼容性报告引用的外部旧图输入保留原路径和摘要，本批不重复打包；它不作为独立自包含模型发布。运行路径和进程号是历史元数据，不能证明当前进程仍在运行。

当前 `sys` 分支维持冻结版本，未合并本增量。下一步仍是通用图 CPU 任务表的双算子路由/完成及生命周期支持，随后验证完整模型正确性；正确性门槛通过后再评价推理性能。
