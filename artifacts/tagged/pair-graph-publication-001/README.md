# 通用图 v2 双算子路由：阶段性发布

本批发布 `mlx-shared-array-v1` 分支的非相邻闭合算子分组、C/RV64 依赖任务表、双源完成记录、生命周期重排及系统审计。阶段顺序仍为 C/C++ 模拟器、系统集成、最后 RTL；本批没有修改加速器 RTL。

- [实现与 ABI 边界](../../../docs/mlx-paired-graph-dispatch.md)
- [组件 003](../pair-graph-003/report.json)：217 项回归、23 个 ASan/UBSan/LSan 重放（21 个设备级、2 个 RoCC 级）、26 项实际 RV64 契约检查。
- [真实 Rocket 003](../pair-graph-rocket-003/report.json)：四个完整登记图均正常退出，99 个源调用、40 个设备窗口、8 次双算子启动。包含非相邻图、8-batch 矩阵，以及正常/扰动的三步 token 与 cache 回馈。
- [镜像重建审计 004](../pair-graph-image-audit-004/report.json)：四个 CPU ELF、任务描述符、输入载荷及检查器逐字节重建一致；[43 项审计器检查](../pair-graph-image-audit-tests-003/regression.xml)覆盖坏来源/工作量/上下文/事件、未终态、参考 token 回填及 cache 重置。

完整公开 Llama2 程序仍保留 6181 个源节点，编译成 873 对（192 对非相邻）、8284 个 CPU 任务。全部矩阵 batch 封装进相应描述符，不因任务数量减少而省略算量。这里只发布编译/地址计划与输入摘要，没有新路径完整模型的执行结果。

[manifest.json](manifest.json) 绑定本批 158 个文件（32332273 字节；不含本索引及 manifest 自身）的摘要，并记录发布前来源/结果交叉核对。23 份 sanitizer JSON 与已发布 release report 逐字节相同，故不重复存放；特殊观察用例的重放 job 已包含，其日志输出使用新路径。

产物包含实际小图输入、C 源码、小型 ELF、描述符、载荷、终态设备结果和全部重建审计记录。没有包含模型权重、宿主模拟器大二进制、构建目录、环境链接和仍在运行的完整模型产物。历史绝对路径、PID、构建/运行库摘要保留用于溯源，复现时应按脚本生成新目录；它们不是当前进程存活证明。完整模型的原始程序/检查点不在此包中，编译记录保留其摘要。

首次系统尝试 001 的构造失败日志和终态记录一并保留：旧观察器拒绝新增消费者元数据，模型尚未启动任务。其旧来源摘要不声称与修复后源码一致。其他开发/验证脚本失败历史说明见实现文档，不被改写为通过。

`sys` 仍保持旧完整运行的冻结版本，未合并本分支。完整 MLX 模型与全部输入、GPU 数值门槛、一般 CDC、完整系统推理性能及 RTL 均未完成，本发布不是这些目标的验收证书。
