# 完整模型原生配对入口：组件发布

本批发布[原生 C++ 模型入口及审计](../../../docs/mlx-native-paired-model-runner.md)。Python 负责绑定、编译、运行管理和核验，周期及数值执行由既有 C++ 共享阵列/块事件后端完成；没有替换为 Python 模型执行，也没有修改 RTL。

- [145 项回归](../native-ready-model-001/regression.xml)通过。
- [15 个 ASan/UBSan/泄漏检查重放](../native-ready-model-sanitizers-001/report.json)通过：5 个正常数值用例、5 个预期数值失败用例、5 个周期限额拒绝用例。失败记录没有改写为正常完成。
- 正常/扰动三步生成、非相邻配对、完整广播矩阵 batch 和尾部形状均有实际 C++ 输出读回；篡改源、批次、工作量、依赖、资源、模板、物理事务和内存回收的证据被拒绝。
- 完整模型启动前直接核对实际 safetensors 头部及全部参数范围，不只信任配置中的规模标记。

[manifest.json](manifest.json) 绑定本批 140 个文件、3794256 字节（不包含本索引和 manifest 自身）。保留正常及失败尝试的源码输入、进程状态、实际输出和比较结果；测试输入中的历史绝对路径按原记录保留，复现应由测试/runner 创建新目录。

完整公开 dense Llama2 的原生配对尝试已另行启动，保留 6181 源、873 对和全部 6,738,415,616 参数，但尚无终态。本发布不包含该运行的任何结果，也不包含模型权重、宿主大二进制、构建目录或环境链接。原生控制 leaf 不是实际 Rocket CPU，预装载不是 CPU/DMA；原生结果与两个 Rocket 完整尝试分别审计。

分支为 `mlx-native-e2e-v1`，从已验收 `258364f` 建立。两个既有工作树中的三个长运行保持冻结，`sys` 未合并。所有完整模型/输入、原 GPU 数值门槛、系统性能、一般 CDC 与 RTL 仍未完成。
