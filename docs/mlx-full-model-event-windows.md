# 完整模型窗口编译与真实布尔见证

本增量将完整源图清单连接到 matrix/vector/memory/control 四类事件编译器，并从一次完整 C++ 数值执行取得 BERT 的动态布尔输入。**尚未执行完整事件图，也没有新的 Chipyard 整模验收结果。**

## 完整 C++ 只读导出

`run_mlx_event_witness` 先核对配对目标程序与已验收原生微程序程序：除后端／调度选项和 block-pipeline 计划外，节点、机器字、资产、结果及模型身份必须一致。使用原先验收的二进制、程序和运行库，仅添加已有的只读 observation 参数；不修改原生执行器或正在运行的六个任务。

`bert-event-witness-full-001` 完整运行退出 0，宿主耗时 354.708 秒。去除新增 observation 字段并归一化输出文件路径后，完整执行报告与原结果一致；所有最终 logits 逐位一致，QA 结果保持 Zurich／Zurich／Oslo。这是完整 C++ 微程序数值重放，不是配对时序、Rocket CPU 或作者 hybrid 通过。

取得的真实数据：

- guard 源 21／1009／2038 的实际布尔值，来自前驱 20／1008／2037；值分别为 true／false／false。
- where 源 1038／2067 的谓词，来自前驱 1035／2064；各按真实广播关系展开为 4,096 项。

输入、源／二进制／运行库摘要、完整终态、原始 observation bin、最终结果和见证值共同绑定。没有把参考 logits 或观测持续时间写入事件模型。当前导出 runner 专门验收 QA 布尔见证；Llama2 的 argmax 还需要实际 RV64 分支路径重放，不能用最终 token 代替全部比较分支。

## 从完整程序到窗口

`WindowCatalog` 按原编译程序重新演算全部 affine layout，并核对 memory_program。每个窗口保留原始／降级源 ID、父依赖、batch、真实输入输出 root/shape/stride/offset、release，以及矩阵的 A/B 广播 batch 索引和逻辑平坦起点。

矩阵事件编译器使用窗口的逻辑 M/N/K，真实高维和非连续布局另保留在 binding 中。地址换算为 root 基址加上布局 offset／stride 导出的字节偏移，不能把窗口的逻辑二维形状当作原张量已经连续化。当前只编译并验证这些绑定，事件核心尚未逐请求执行这些地址。

向量模式可复用与数值身份无关的相同 shape/dtype/标量参数/机器字；每次使用保留独立 SSA 绑定。循环计数完整保留，不截断波次。遇到缺失的 where／guard／argmax 实际见证时明确登记待补窗口，不插入预期值。
