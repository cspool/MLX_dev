# 源级生命周期、依赖图和完整程序批次清单

本增量将源准入、前端窗口容量、整源依赖及多窗口完成发布加入 C++ 事件核心，并用真实数据依赖图验证。完整 Llama2/BERT 的图清单已核对，但全部微程序尚未按需装入事件运行器；不能将清单或测试图作为整模事件执行通过。

## 原生规则与 C++ 接入

schema v6 在显式 `source_tick_order=true` 时可提供 `source_graph`。每项包含唯一 `source_operator_id`、`family`、`parents`、按批次次序排列的 `windows`；每个窗口列出实际块 ID。输入必须覆盖全部源和全部块，父源先声明，拒绝重复、漏项、错属资源域和循环／前向父依赖。

- 已启动源即占用前端窗口，即使尚未获得 PE/RF/SPM。不能以当前驻留块数量代替活动源数量。
- 仅在共享 DMA 通路空闲时准入新源；已活动的其他前端继续推进，不因此整体串行化。
- 控制源、非 view 搬运源分别最多一个活动前端；它们仍可与阵列源并发。
- 一个窗口的所有块退休后才进入下一窗口；所有窗口结束后才发布源完成并唤醒后继。批次之间保留同一源的前端槽。
- `source_intervals` 分别记录源开始／发布以及每个窗口的起止；最终要求源、块、服务和前端槽全部排空。

该模式仍不替代 CPU 取指、完整物理内存系统或流式 block-pair 协议。源依赖是 whole-source publication，原编译程序中的 streaming pair 保留在清单中等待接入，不通过删除配对计划或扩大资源规避。

## 真正消费前驱输出的数值验证

`model_array_graph_events.py` 将完整阵列窗口及源表接入此接口；输入的 `group_output` 必须指向已声明的前驱窗口，且生产者须为祖先或同源较早窗口，shape/dtype 必须一致。

独立 C++ 数值对照驱动直接引用前驱实际计算输出的存储，后继不会拿到 Python 参考中间值。测试用的独立逐窗口参考另行生成，仅用于最终逐字节核对。驱动采用固定延迟 TensorMemoryPort 与共享阵列 DMA 服务槽，所有源保留并发。

`array-graph-event-alignment-001` 重跑 8 个六源／七窗口依赖图：矩阵双窗口、分叉、合并、独立并发源及归约；FP16/FP32、默认/非默认端口节拍，前端容量为 2 或 4。原生和事件总周期、源起止、窗口起止、前端峰值一致，全部七个真实窗口输出与独立数值参考逐字节一致。两矩阵窗口的输出分别有自己的缓冲区，因此它验证多窗口调度／发布，不声称已验证整模型批次共享一个输出分配及广播地址映射。

另有未获得 PE 的源仍持有前端槽、控制前端独占、等待共享 DMA 空闲、父依赖与窗口漏项拒绝检查。累计 `event-source-graph-regression-001` 293 项回归通过，`event-source-graph-safety-001` 291 次 ASan/UBSan/LSan 重放（248 正常、43 预期拒绝）。trace 审计重新计算源／窗口边界、依赖可见性、准入空闲门槛和前端容量。

此前 32 个独立并发窗口组和四类单窗口对照在当前引擎重新通过；完整模型误差仍不可用。

## 完整模型的真实源图清单

`compile_mlx_event_graph_plan` 从当前冻结配对程序提取全部数据／控制依赖、split 子值、原始／降级身份、矩阵 batch 广播几何、结果角色和动态见证要求。对矩阵重新核对 M/N/K、输入 batch 与输出 shape，不能只按输出算量估计窗口数。发布包包含完整编译程序 JSON，重建清单不需要读取 checkpoint 权重。

| 模型程序 | 原始源调用 | 降级步骤 | 全部后端窗口 | 源依赖边 |
| --- | ---: | ---: | ---: | ---: |
| Llama2 配对 | 6,181 | 6,181 | 12,133 | 7,835 |
| BERT QA 配对 | 1,141 | 3,046 | 3,838 | 9,824 |

Llama2 包含 6,822 个矩阵 batch 窗口；BERT 包含 1,083 个。Llama2 仍需三个 argmax 的各 31,999 个真实分支取向，以及 where 谓词；BERT 仍需三个实际 guard 布尔值和两组各 4,096 个 where 谓词。这些是待绑定的实际数据，不以参考 logits、固定常量或观测周期替代。

清单位置 `full-event-graph-plan-001/{bert,llama2}.json`；`full_event_lowering_complete=false`、周期为 null。它没有执行模型、没有验证 checkpoint 数值，也没有放行性能结论。

## 下一步与优先级

按需装入完整源的所有事件窗口，接入实际 batch 输出/广播地址、控制／搬运混合及动态见证、有限事件槽的逐块配对完成协议、模板装载和物理访存边界，然后完成整模事件覆盖审计与并发端到端误差比较。事件 IR 仍有容量界限，不得通过截断整模来绕过。

六个既有整模运行和捕获源码保持冻结，Chipyard 整模仍待终态验收。GPU 新实验后置，RTL/PPA 最后，本增量未改 RTL。
