# H81 protocol: target-free FFT steady-state folding

H81 tests the independently motivated diagnosis from H80: q=1/2 is below the
steady-state region of the variable-depth FFT-CMP wavefront. It changes no
stage, PE, FU, route, memory, SIMD, or trip-ratio rule.

For both H80 topologies, q=4/8 are the affine fit anchors and newly executed
q=16/32 are held out. All four q values run twice from configs regenerated by
the unchanged H80 compiler. Support requires every held-out cycle prediction
within 5%, exact q-linear instruction/event/route/pipeline/FU work, exact H79
full-work conservation, byte-identical replays, and a positive slope.

The selection is target-free: it follows H80's monotonically rising local
slopes and consumes no Figure 20 performance value. Passing would validate a
fixed-memory FFT component estimator only; compressed Attention, scratchpad/
off-chip effects, Xavier execution, and Figure 20 comparison remain excluded.

`artifacts/results/fft-steady-state-folding-run086.json`.
